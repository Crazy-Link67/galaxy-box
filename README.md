## 📖 Overview

**GALAXYBOX** is an expansive God Sandbox Simulator featuring a dual-mode engine: classic **2D Pixel Art Mode** and full **3D WebGL 2.0 Perspective Mode**! As an all-powerful deity, you command nature, unleash apocalypse upon civilizations, build thriving worlds from scratch, possess and pilot massive dragons, titans, mechs, and combat vehicles, equip weapons onto your subjects, and perform ancient cosmic rituals across a persistent cellular matrix.

Switch seamlessly between 2D and 3D at any time with the **`V`** key or top HUD button!

Everything runs in real time at **60 FPS** with **zero build steps or external dependencies**—simply launch `index.html` in any modern web browser!

## 🌐 Dual 2D / 3D Engine Architecture

* **Instant 2D / 3D Toggle**: Press **`V`** or click **`🌐 3D`** on the top bar to switch instantaneously between 2D tactical view and immersive 3D perspective view.
* **Continuous Heightfield Elevation**: Every tile has true 3D elevation. Mountains rise into jagged peaks, valleys dip into deep ocean trenches, and nukes/meteors physically carve 3D craters!
* **360° Orbit Camera**:
  * **Right-Click Drag / Alt + Drag**: Orbit 360° around the world with polar tilt.
  * **WASD / Middle-Click Drag**: Smoothly pan the camera across the landscape.
  * **Mouse Wheel / Pinch**: Zoom from close-up unit inspection to planetary orbital view.
* **Pinpoint 3D Raycasting**: All 60+ tools (brushes, powers, spawns, bombs, inspector) work with 100% accuracy in 3D using hardware heightfield raymarching.
* **3D Dynamic Lighting & Atmosphere**: Directional sun lighting, water specular highlights, pulsing lava glow, acid sizzle, and atmospheric depth fog.
* **Spatial Ground Drop Shadows**: Soft shadow billboards projected underneath walking, driving, and flying units. Flying dragons and helicopters soar high into the skies with proportional ground shadows!

## 🎮 Direct Creature Control ("Possess Mode")

Take direct control of **Dragons, Mechs, Titans, Beasts, or Vehicles**:

1. Click the **"🎮 Possess / Control"** tool in Category 5 and click on any creature or vehicle.
2. Alternatively, hover your cursor over any entity and press the **`C`** key.
3. Spawning **Dragons**, **Mechs**, **Crabzilla**, **Kaiju**, or **Vehicles** automatically puts you in the pilot's seat!

### Controls While Possessing:
| Key / Input | Action |
| :--- | :--- |
| **`W` `A` `S` `D`** / **Arrows** | Real-time movement / flight / drive |
| **Left-Click** / **`Space`** | Primary Attack (Dragon fire breath, Mech gatling, Tank cannon, Laser eyes) |
| **Right-Click** / **`Q`** / **`E`** | Special Ability (Dragon firestorm dive, Mech rocket barrage, Seismic stomp) |
| **`Escape`** | Exit control and return to God View |

## 🌌 The Great Galaxy Sacrifice Ritual

Perform the ancient cosmic ritual to permanently unlock the secret **Spiral Galaxy** world generator template:

1. Open the **Creatures tab (5)** and spawn a **Galaxy Guardian (`✨`)**.
2. Switch to **Destruction & Chaos (1)** and select the **Atomic Nuke (`☢️`)** or **Nuke Missile (`🚀`)**.
3. Strike the Galaxy Guardian directly with the nuclear blast!
4. **The Supernova**: The guardian's core implodes into a cosmic supernova, transforming surrounding terrain into **Cosmic Nebulae** and **Stardust Land**.
5. **The Unlock**: The celebration banner appears, and the secret **Spiral Galaxy** map template is permanently unlocked in the World Generator!

## 🛠️ Project Structure

```
galaxy-box/
├── index.html          # Main HTML5 UI markup, canvases, HUD docks, and modals
├── style.css           # Retro pixel aesthetic, glassmorphism HUD styles, and cinematic mode
├── README.md           # Game documentation and manual
└── js/
    ├── audio.js        # Procedural Web Audio API SFX synthesizer (zero audio files needed)
    ├── particles.js    # Zero-allocation particle pool engine for explosions, smoke, spells
    ├── world.js        # Cellular automata tile grid, terrain generation, and fluid physics
    ├── entities.js     # Entity ECS, species sprites, kingdoms, weapons system, AI behaviors
    ├── disasters.js    # Nuke missiles, rifts, ion cannons, forcefields, weather, and disasters
    ├── renderer.js     # Micro-pixel renderer, edge shading, kingdom borders, weapon sprites
    ├── ui.js           # Category menus, tool palettes, inspector, creator studio, diplomacy ledger
    └── game.js         # Core game loop, input dispatcher, possession controller, save engine
```

## 🚀 Getting Started

No installation, build steps, or server required!

1. Clone or download the repository:
   ```bash
   git clone https://github.com/your-username/galaxy-box.git
   ```
2. Double-click **`index.html`** or run:
   ```bash
   Start-Process index.html
   ```
3. Play immediately in Google Chrome, Microsoft Edge, Mozilla Firefox, or Apple Safari!
